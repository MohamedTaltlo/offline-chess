# MT Chess 2.0.0 — Native Android
Completely native Java Android application, no WebView, HTML, JavaScript, or INTERNET permission. Local chess engine, four difficulty levels, fixed board, drag/tap moves, unlimited undo, castling, promotion, en passant, repetition, local save, native Android dialogs, three board styles. White always at bottom. Chessnut piece artwork by Alexis Luengas, Apache 2.0, see art/chessnut/NOTICE.txt. Build requires JDK17, Gradle8.9, Android SDK35 and Python CairoSVG to rasterize the bundled SVGs. Run javac -d /tmp/chess app/src/main/java/com/mt/chess/Chess.java tests/NativeChessTest.java && java -cp /tmp/chess com.mt.chess.NativeChessTest, python scripts/render_pieces.py, gradle assembleDebug. APKs are signed with the CI debug key; a previous installation signed by another key must be uninstalled before installing.
